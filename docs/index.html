Unit Converter

A small Python command-line converter for length, temperature and weight.

Implemented features

  • Length: mm, cm, m, km, in, ft, yd, mi
  • Temperature: Celsius, Fahrenheit, Kelvin, with an absolute-zero check
  • Weight: mg, g, kg, t, oz, lb, st, with a negative-weight check
  • Automated checks: pytest suite run by GitHub Actions on every push and pull request

How to run it

git clone https://github.com/mehdibuilds/unit-converter.git
cd unit-converter
python app.py length 5 km mi
python app.py temperature 100 c f
python app.py weight 2.5 kg lb

# run the tests
pip install -r requirements.txt
pytest
